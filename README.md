# המגניבולים

רשת חברתית בסגנון TikTok, בעברית — פיד עם לייקים ותגובות, לייבים עם וידאו (WebRTC) וצ'אט חי, ועוזר AI בשם "מגניב" (מבוסס Groq).

## הרצה מקומית

צריך שני תהליכים במקביל: שרת ה-Next.js ושרת ה-Socket.io (לצ'אט חי ולסיגנלינג של WebRTC).

```bash
npm install
npm run dev:all
```

זה מריץ את שניהם יחד (Next בפורט 3000, Socket.io בפורט 4001). אפשר גם להריץ כל אחד בנפרד עם `npm run dev` ו-`npm run socket`.

בפעם הראשונה, צריך גם ליצור את מסד הנתונים ואת חשבון הבעלים:

```bash
npx prisma db push
npm run seed
```

## התחברות כבעלים (מנהל ראשי)

שם המשתמש והסיסמה של חשבון הבעלים מוגדרים בקובץ `.env` (`OWNER_USERNAME` / `OWNER_PASSWORD`), ונטענים למסד הנתונים בהרצת `npm run seed`. חשבון זה מקבל הרשאות מנהל אוטומטית ולא ניתן לחסום או להוריד ממנו הרשאות מפאנל הניהול.

**מומלץ לשנות את הסיסמה בקובץ `.env` לפני שימוש אמיתי**, ולהריץ שוב `npm run seed` כדי לעדכן.

## משתני סביבה (`.env`)

| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | נתיב למסד SQLite המקומי |
| `JWT_SECRET` | מפתח סודי לחתימת session tokens — ייחודי לכל סביבה |
| `GROQ_API_KEY` | מפתח API של Groq עבור עוזר ה-AI "מגניב" (ספק ראשי) |
| `OPENROUTER_API_KEY` | מפתח API של OpenRouter — משמש כגיבוי אוטומטי כשל-Groq יש הגבלת קצב (429) |
| `OPENROUTER_MODEL` | מודל ה-fallback ב-OpenRouter (ברירת מחדל: `google/gemma-4-26b-a4b-it:free`) |
| `OWNER_USERNAME` / `OWNER_PASSWORD` | פרטי חשבון הבעלים (מנהל ראשי) |
| `SOCKET_PORT` | פורט שרת ה-Socket.io (ברירת מחדל 4001) |
| `NEXT_PUBLIC_SOCKET_URL` | הכתובת שהדפדפן משתמש בה כדי להתחבר לשרת ה-Socket.io |

**חשוב:** `.env` לא נכלל בגיט (ראה `.gitignore`). לפני deploy לסביבת ייצור אמיתית, יש להחליף את `JWT_SECRET` ואת סיסמת הבעלים בערכים חדשים וסודיים משלכם.

## מבנה עיקרי

- `src/app` — עמודי Next.js (App Router): `/login`, `/signup`, `/feed`, `/live`, `/live/[roomId]`, `/ai`, `/admin`.
- `src/app/api` — API routes: אימות, פוסטים, לייקים, תגובות, לייבים, AI, ניהול.
- `server/socket-server.ts` — שרת Socket.io נפרד: צ'אט חי, לייקים על הודעות, ריאקציות (❤️), וסיגנלינג ל-WebRTC.
- `prisma/schema.prisma` — סכמת מסד הנתונים (SQLite).
- `prisma/seed.mjs` — יוצר/מעדכן את חשבון הבעלים.

## פיצ'רים

- **פיד**: פוסטים עם טקסט/תמונה, גלילה אנכית בסגנון TikTok, לייקים ותגובות.
- **לייבים**: שידור וידאו אמיתי מהמצלמה (WebRTC, host → viewers), צ'אט חי, לייקים על הודעות צ'אט, ריאקציות לב מרחפות.
- **מגניב AI**: צ'אט עם עוזר AI מבוסס Groq, זמין בעמוד `/ai`.
- **פאנל ניהול** (`/admin`, למשתמשי ADMIN בלבד): חסימת משתמשים למשך זמן מוגדר (עם סיבה), ביטול חסימה, הענקת/הסרת הרשאות מנהל. חשבון הבעלים מוגן מחסימה ומשינוי הרשאות.
- **אבטחה**: סיסמאות מגובבות (bcrypt), session tokens חתומים (JWT), הגבלת קצב על התחברות/הרשמה, CAPTCHA מתמטי אנטי-בוט.
- **PWA**: ניתן "להתקין" את האפליקציה מהדפדפן (למשל Chrome/Edge → "התקן אפליקציה") ולפתוח אותה כחלון עצמאי.

## הערות לפני production אמיתי

זהו יישום מקומי/self-hosted עם מסד SQLite ושרת socket יחיד — מתאים להרצה מקומית או שרת יחיד קטן. ל-production אמיתי בקנה מידה גדול כדאי לשקול: מסד PostgreSQL, שירות וידאו/סטרימינג ייעודי (כרגע ה-WebRTC הוא mesh ישיר host↔viewers, לא מתאים להמון צופים), ואחסון קבצים בענן במקום דיסק מקומי.
